# A made-up vocabulary, for tests only

These rows are not OMOP's. The concept ids (2,000,000,001 and up, a range OMOP leaves to local concepts) and names
were made up for the tests; only the vocabulary ids and codes are real codes, so the mapper's lookups can be checked.
Never load this into a CDM. Download the real vocabularies from Athena (https://athena.ohdsi.org) under their terms.
